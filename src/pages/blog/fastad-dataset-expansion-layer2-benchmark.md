## 一、现实的重锤：无监督异常检测的“基线漂移”与标定失效

### 1. 实验室理想与 653 个真实现场视频的冲突

FastAD（基于预训练 WideResNet-50 骨干抽取正常分布、通过马氏距离计算异常热力图）的核心优势在于**无需缺陷标注，仅靠正常图片即可冷启动**。但在系统最初的研发阶段，开发人员仅使用了来自 3 个现场历史录像的约 300 帧样本作为训练集。

当这套系统推向现场，面对来自各线路机务段反馈的 **653 个误报视频**时，无监督模型遇到了严峻的挑战：
- 车体在强烈阳光直射下产生的**镜面反光 (Specular Glint)**；
- 动车进出隧道产生的**剧烈明暗交替与深暗阴影 (Shadow Tunnel)**；
- 高速运行中横跨视场上方的**密集接触网吊弦与绝缘支撑 (Catenary Droppers)**；
- 阴天、雨天以及车顶绝缘漆面反光率的动态变化。

原先在 3 个干净视频上学到的“正常分布特征流形”，根本无法包容真实铁路线路上的复杂环境扰动。

### 2. 异常评分倒挂：为什么正常帧会测出 21.2 分？

在运行阈值标定工具后，评测看板输出了令人震惊的分布数据：

```text
FastAD Layer 3 综合阈值标定与基准评测看板:
1. 全图异常评分分布 (img_score Percentiles):
   - 负样本 (Normal 150帧) : Min=6.41 | P50=8.0 | P90=12.04 | P95=14.01 | Max=21.24
   - 正样本 (Anomaly 112帧): Min=2.79 | P50=9.6 | P90=14.47 | P95=16.62 | Max=18.87
------------------------------------------------------------------------
2. 各细分工况统计对比:
   [负样本]  specular_glint     (11帧) -> img_score [P50:  7.4, Max: 13.3]
   [负样本]  shadow_tunnel      ( 3帧) -> img_score [P50: 13.9, Max: 21.2]
   [负样本]  catenary_droppers  (27帧) -> img_score [P50:  8.0, Max: 15.9]
   [负样本]  clean              (30帧) -> img_score [P50:  7.8, Max: 14.1]
   [正样本]  dirt               (76帧) -> img_score [P50:  9.7, Max: 18.9]
   [正样本]  foreign_object     ( 3帧) -> img_score [P50:  3.3, Max:  3.5]
   [正样本]  structural_anomaly ( 1帧) -> img_score [P50:  5.2, Max:  5.2]
```

数据呈现出严重的**分布倒挂与混叠**：
1. **正常背景被误判为极度异常**：在阴影或隧道工况下，正常负样本的 `img_score` 飙到了 **13.9 ~ 21.2**；
2. **真实致命缺陷反而分数较低**：受电弓框架断裂的真实缺陷分数仅为 **5.2**，绝缘子挂载塑料袋/异物仅为 **3.3 ~ 3.5**！

### 3. calibrate_thresholds 标定网格搜索的崩塌

由于分布倒挂，传统的网格搜索标定脚本 `calibrate_thresholds.py` 试图在 `img_threshold` 与 `pixel_threshold` 的组合中寻找 F1 最大值，得出的推荐结果却是：
```text
[受电弓结构异常]
-> 最佳参数组合 : img_threshold=5.0, pixel_threshold=4.0, min_defect_area=500
-> 评测指标效果 : Precision=0.0%, Recall=0.0%, F1=0.0000, 现场误报率(FAR)=28.17% (FP=20/71)
```
**F1 为 0，误报率高达 28.17%！** 
原因非常纯粹：当正常样本的背景基线漂移到 8~14 分时，如果阈值设为 5.0，大量正常帧被直接判定为异常；如果阈值设为 14.0，真正的结构断裂（5.2分）直接被漏检。单一依靠粗暴的“调阈值”已经无法解决本质问题，必须进行**底层数据治理**与**模型特征层重构**。

## 二、科学评测基石：数据治理与双集绝对物理隔离

### 1. 拒绝数据泄露：构建 134 帧纯净现场测试基准库

为了建立客观、不受主观意志干扰的模型评估标尺，我们首先从 653 个现场误报视频与故障案例中，抽离出一个具有高可信度的评测集 `/home/ibd/jyb/Dataset`：

- **负样本集 (Normal，54 帧)**：覆盖 10 类极易产生虚警的现场极端开集工况（包含镜头反光 `specular_glint`、隧道暗影 `shadow_tunnel`、密集吊弦 `catenary_droppers`、车顶反光变色 `clean` 等）；
- **正样本集 (Anomaly，80 帧)**：包含镜头真实泥浆与雨滴污渍 76 帧、悬挂异物 3 帧、受电弓碳滑板断裂/结构异常 1 帧；
- **元数据同步机制**：编写 `sync_dataset_manifest.py`，生成标准的 `manifest.json` 与 `manifest.csv`。

> ⚠️ **工业落地红线**：评测集与后续任何训练扩充集实施**绝对物理隔离**，任何从 653 个视频中抽取用于模型训练的候选帧，严禁与评测集出现交集，杜绝评估虚高。

### 2. 历史训练集精简脱水：消除火花样本的过载偏置

分析原训练集 `/home/ibd/jyb/gongwang_fastad/dataset` 发现：原数据集中包含了高达 239 帧单一历史视频的“大火花背景”。由于样本严重过载，无监督高斯分布的模型中心被大面积火花强光拉偏，导致正常暗光工况被误判为异常。

我们对原训练集执行精简降采样：
- 大火花冗余背景从 239 帧精简压缩至 80 帧；
- 几何姿态倾斜帧保留 50 帧；
- 异物背景帧保留 50 帧；
- 视频基线帧保留 20 帧；
- 精简后的基础骨干集为 200 帧 Train / 68 帧 Val。

### 3. 现场误报视频跨工况抽样与人工质检入库

为了让 FastAD 真正“见识过大风大浪”，我们从 653 个误报视频中横跨 10 种复杂线路工况抽取了 250 帧候选训练帧，输出至独立隔离目录 `/home/ibd/jyb/candidate_train_frames/`。

考虑到误报视频中偶尔夹杂着真正的电弧大火花和微弱镜头脏污，如果直接将它们混入正常训练集，无监督算法就会将缺陷误学为“正常”，导致严重漏检。

因此，引入**人工交互式清洗与审核机制**：
1. 逐帧审核 250 张候选切片，剔除任何带有镜头污渍、强电弧放电的受污染图像；
2. 筛选出 **59 帧纯净、高质量且具有典型光照代表性的真实线路正常帧**；
3. 执行 `merge_reviewed_candidates.py`，将这 59 帧按 8:2 划分注入训练集（47 帧 Train / 12 帧 Val）；
4. 训练集最终收敛为紧凑而极具泛化性的 **Train 247 帧 / Val 80 帧**。

## 三、核心算法突破：Layer 2 浅中层几何特征重构

在数据治理完成后，核心算法架构的选择成为决定性的分水岭：究竟是沿用过去常用的 **Layer 3**，还是切换至更加浅层的 **Layer 2**？

### 1. 物理感受野机理：Layer 2（局部几何）vs Layer 3（全图语义）

在经典 ResNet/WideResNet 结构中：
- **Layer 3（深层高阶语义特征）**：特征图感受野通常大于 **100~150 像素**。这意味着特征向量不仅编码了受电弓本身，还将大片的天空背景、远处的山体隧道、接触网全貌融合在了一起。当列车进出隧道或天气剧烈变化时，深层语义特征发生剧烈翻转，导致马氏距离爆炸（全图 `img_score` 冲破 20+）；
- **Layer 2（中浅层局部几何轮廓特征）**：特征图感受野适中，仅为 **35~50 像素**。这恰好与动车组受电弓的碳滑板厚度、羊角折角弯曲度、铝合金管臂边缘的宽度相吻合！它敏锐地捕获受电弓几何轮廓的“连续性断裂”与“边缘畸变”，同时对全图大尺度的宏观光照、大面积隧道暗斑具有天然的**几何尺度免疫性**。

```
WideResNet-50 骨干网络特征抽象与感受野对比：

输入画面 (256x256)
  │
  ├─► Layer 1 (感受野 ~15px) : 像素边缘、高频噪波 (易受视频压缩振铃影响)
  │
  ├─► Layer 2 (感受野 ~40px) : 碳滑板、羊角、横梁等刚性局部结构  ◄──【最佳几何表征】
  │                           · 对结构断裂敏感，对全图天空阴影脱敏
  │
  └─► Layer 3 (感受野 ~120px): 全图场景上下文、天空大面积光斑  ◄──【语义过拟合源头】
                              · 阴影和隧道导致特征巨幅漂移
```

### 2. 关键参数组合：2_256_reg1e4_nq3_fmq1 的设计精髓

我们对比训练了两个架构变体：
- **Layer 3 架构**：`fastad_layer3_dataset.pt`（layer 3, 256×256, reg=0.01, nq=3, fmq=2）；
- **Layer 2 架构**：`fastad_layer2_256_reg1e4_nq3_fmq1.pt`（layer 2, 256×256, reg=1e-4, nq=3, fmq=1）。

其中 Layer 2 采用的正则化系数 `reg=1e-4` 允许协方差矩阵更精细地贴合局部几何特征，量化参数 `fmq=1` 则保证了空间网格热力图不被过度下采样模糊化。

### 3. 基准测试指标全面对比 (AUROC / PR-AUC 全景看板)

在包含 54 帧真实现场负样本与 80 帧缺陷正样本的基准评测集上，两种模型展现出了断崖式的性能差距：

| 评测维度 / 关键指标 | Layer 3 (`fastad_layer3_dataset`) | Layer 2 (`2_256_reg1e4_nq3_fmq1`) | 性能增益 / 物理表现 |
| :--- | :---: | :---: | :--- |
| **全图异常 AUROC (Global Image)** | 0.7042 | **0.8882** | **大幅提升 +18.4%** |
| **全图异常 PR-AUC** | 0.7812 | **0.9164** | **提升 +13.5%** |
| **正常帧背景评分区间 (`img_score`)** | 6.41 ~ 21.24 (均值 9.8) | **1.62 ~ 2.65 (均值 2.05)** | **背景漂移被彻底压制收敛** |
| **受电弓结构断裂 (`panto_max`)** | 0.9815 | **1.0000** | **完美 100% 线性分离** |
| **缺陷连通域面积 (`blob@3.5`)** | 0.9815 | **1.0000** | **缺陷块 52,155px vs 正常帧 0px** |
| **镜头画面脏污 (Dirt Grid AUROC)** | 0.8123 | **0.9176** | **最佳 F1 跃升至 0.92** |
| **开集悬挂异物 (`cat_max`)** | 0.0741 (失效) | **0.7531** | **异物响应恢复正常正向相关** |

### 4. 受电弓结构断裂的“绝对零度”隔离 (100% 分离度)

最震撼的性能突破发生受电弓结构异常这一核心安全项上：
- 在 **54 帧覆盖各类恶劣工况的现场正常帧** 中，经过 Layer 2 处理后，受电弓内部最高像素异常得分 `panto_max` 的极大值仅为 **2.65**；
- 在设定 `pixel_threshold = 3.5` 后，所有 54 帧正常现场样本检测出的缺陷连通块面积全为 **0 像素**；
- 而在真实的受电弓断裂样本上，`panto_max` 高达 **5.25**，断裂连通域面积达到惊人的 **52,155 像素**！

这意味着在结构断裂检测维度，Layer 2 达成了绝对的 **零漏报与零误报**。

## 四、边缘端极速落地：8.4MB TensorRT FP16 编译自检

确定了模型在精度上的卓越表现后，必须将其转化为嵌入式车载端（NVIDIA Jetson AGX Orin）可执行的极速硬件引擎。

### 1. 骨干网络剪枝与 FP16 序列化构建

FastAD 的推理瓶颈集中在 WideResNet 骨干网络的卷积前向传播上。传统做法是直接导出包含后处理的完整模型，而我们采用**骨干网络解耦与显式剪枝方案**：
1. **网络剪枝**：针对 Layer 2 模型，骨干提取器仅需执行到 `conv1 -> bn1 -> relu -> maxpool -> layer1 -> layer2`。其后的 `layer3`、`layer4`、`avgpool` 以及 `fc` 全连接层被物理剪除；
2. **ONNX 中转**：通过 `tools/export_tensorrt.py` 导出剪枝后的轻量 ONNX 计算图（仅 16.5 MB）；
3. **TensorRT FP16 构建**：在目标硬件上调用 TensorRT Builder 开启 FP16 半精度模式，融合多层 Conv+BN+ReLU 算子，生成序列化引擎 `fastad_layer2_256.engine`。

### 2. 0.999995 极高余弦相似度数值校验

为了验证半精度量化与算子融合是否造成精度退化，自动化导出套件在生成引擎后立即执行了 PyTorch FP32 与 TensorRT FP16 特征图的双向数值对齐自检：

```text
[TrtFastADBackboneRunner] FastAD Engine 初始化完成 | 输入: ['images'] | 输出: ['layer2_features']
[INFO]   FastAD 特征图余弦相似度: 0.999995 (目标 >= 0.9999)
[INFO]   FastAD 特征图最大绝对误差: 0.061768 | 平均绝对误差: 0.001037
[INFO] ✅ FastAD 骨干网络 TensorRT FP16 数值精度校验合格！
```
余弦相似度达到 **0.999995**，完全消除了量化溢出与数值漂移隐患。

### 3. 全链路端到端 16.6ms / 60 FPS 延迟实测

在宿主机 GPU 上对完整推理流水线（`720x1280` 原画输入 -> GPU 原生硬件缩放归一化 -> TensorRT 骨干特征提取 -> 高斯核平滑与马氏距离度量）执行压力测试：

```python
# 压力测试核心指标
TRT Layer2 Backbone 单独推理耗时: 7.52 ms
TRT Layer2 全流水线端到端耗时: 16.67 ms (吞吐达到 60.0 FPS)
Engine 文件体积: 8.4 MB (相比 Layer 3 的 48.3 MB 缩小了 82.6%)
```

## 六、工业视觉落地启示录

回顾本次 FastAD 在 653 个现场误报视频上的攻坚战役，我们总结了三条极具普适性的工业无监督视觉落地法则：

1. **工业单类异常检测的生命线是“纯净且多样”的负样本集**：
   单类学习（One-Class Learning）不是“随便挑几百张图片丢进去训练”。一个被大火花强光偏置或场景同质化的训练集，在开集线路面前会迅速发生基线崩塌。从现场视频中精细化抽样、严格人工质检、剔除微小缺陷并保持多样性，是压制基线漂移的第一要务。
2. **结构缺陷检测，浅中层特征（Layer 2）优于深层语义（Layer 3）**：
   深度卷积网络的深层特征具备很强的语义不变性与超大感受野，但在刚性物理部件（受电弓、轴承、齿轮）的缺陷筛查中，这种“大尺度语义”反而是误报的罪魁祸首。适度收敛感受野至部件物理尺度（Layer 2 的 35~50 像素），能精准捕捉轮廓畸变，并天然屏蔽环境大背景的干扰。
3. **科学的指标体系是算法迭代的指南针**：
   不要在模型泛化能力尚未理顺前盲目调阈值。通过 AUROC 与 PR-AUC 评估模型本身的流形分布分离能力；一旦分布实现彻底分离，工程阈值即可轻松设定在巨大的安全鸿沟之间，实现零漏报与零误报的兼顾。
