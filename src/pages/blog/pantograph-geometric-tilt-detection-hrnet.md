## 一、业务痛点：为什么受电弓倾斜监测是工业视觉的“硬骨头”？

受电弓是动车组从接触网获取电能的咽喉部件。高速受流时，受电弓碳滑板必须与接触网导线保持水平接触并维持恒定接触压力。如果由于单侧弹簧盒断裂、气囊漏气失衡、导向杆卡阻或异物挂扯，导致受电弓发生**横向倾斜（Tilt）**：
1. **单侧受力集中**：受电弓一侧剧烈受压，另一侧脱离接触网，产生长达数米的强烈离线大火花（Spark）；
2. **引发灾难性“钻弓”**：倾斜翘起的羊角极易钻入接触网悬挂零件或分段绝缘器下方，在几毫秒内将接触网直接撕断，造成整条干线瘫痪。

```
       正常水平受流 (平衡接触)                  倾斜异常受流 (单侧脱弓、强拉弧风险)
接触网: --------------------------      接触网: ---------/----------------
受电弓: [========================]      受电弓:         / (右端下塌，左端翘起)
           ||                ||                       ||                ||
```

但在真实的巡检视频中，视觉检测面临着极端恶劣的环境挑战：
- **碳滑板长期滑磨磨损**：滑板中央接触区在运行数万公里后厚度动态变薄、表面拉毛，直接通过边缘检测算绝对直线误差极大；
- **强离线电弧暴晒**：夜间离线拉弧产生数万流明的剧烈白光过曝，造成特征边缘模糊；
- **车体高速振颤与过弯侧滚**：列车在曲线区段有外轨超高角，车顶相机与受电弓整体发生刚体倾斜，使传统的图像坐标系水平判据彻底失效。

## 二、特征拓扑进化：从 10 点到 4 刚性关键点的几何解耦

在项目初期，业界常采用沿碳滑板上表面密集布置 6~10 个关键点的标注方案。但在工程迭代中，我们发现这种密集标注在实战中存在致命缺陷：

```
初期方案 (6~10点密集型，易受磨耗污染):
   (1)---(2)-------(3)--------(4)-------(5)---(6)   <-- 碳滑板磨耗工作面 (厚度动态变化)
           \-------(7)========(8)-------/           <-- 下托架

演进方案 (4点刚性解耦型，避开接触磨耗区):
   P1 (左羊角顶点) ============================== P4 (右羊角顶点)  <-- 刚性工作跨度
       \                                           /
        \--- P2 (左支撑铰点) ======= P3 (右支撑铰点) ---/            <-- 刚性安装基准
```

### 1. 为什么坚决舍弃中央滑磨点？
受电弓碳滑板是用碳陶复合材料制作的易耗件。在高速运行中，接触线在滑板中央沿之字形滑行，滑板中心会逐渐磨出数毫米的凹槽弧度。如果在滑板表面打点：
- 关键点垂直位置会随磨损深度不断漂移；
- 磨耗凹陷会被误判为结构弯曲或倾斜。

### 2. 最终确定的 4 刚性关键点拓扑

| 标识 | 拓扑命名 | 物理结构解剖位置 | 刚性特征与几何优势 |
| :---: | :--- | :--- | :--- |
| **P1** | `p1_left_horn` | 碳滑板左端羊角弯折顶点 | 位于受电弓最外侧，**远离中央接触网摩擦区**；跨度大，角度分辨率高 |
| **P2** | `p2_left_support` | 下横梁与左 U 形支架 T 型铰接点 | **受电弓内部刚性转折角点**，灰度反差极强，不受任何磨损影响 |
| **P3** | `p3_right_support`| 下横梁与右 U 形支架 T 型铰接点 | 下横梁右侧对称刚性铰接点，与 P2 共同构成弓头底座刚性机械基准线 |
| **P4** | `p4_right_horn` | 碳滑板右端羊角弯折顶点 | 位于右侧最外端，与 P1 构成上滑板姿态线，两端无磨损、刚性绝对稳定 |

通过这一精简，**标注成本直降 60%，模型定位抖动降低 40%**，并从几何根源上彻底免疫了碳滑板摩擦磨损对测角的干扰。

## 三、姿态网络落地：HRNet-W32 亚像素回归与训练调优

在骨干网络选型上，我们摒弃了传统的自顶向下两阶段先检测后下采样的编解码器（如普通 ResNet / SimpleBaseline），选用了在整个特征提取过程中始终保持高分辨率表征的 **HRNet-W32**（*High-Resolution Network*）。

![HRNet 多分辨率并行特征交换机制](https://raw.githubusercontent.com/leoxiaobin/deep-high-resolution-net.pytorch/master/figures/hrnet.png)
*HRNet 始终并联保持高分辨率分支，并在不同尺度间反复多尺度融合，确保关键点像素级热图定位的锐利度与保真度。*

### 1. 核心训练超参数配置
- **输入分辨率**：$384 \times 288$（宽高比匹配受电弓长横条结构）
- **输出热图分辨率**：$96 \times 72$（$4 \times$ 下采样，输出 4 通道高斯热图，$\sigma=2$）
- **解码算法**：标准双线性插值 + DarkPose 亚像素泰勒展开极值修正
- **数据增强**：随机水平翻转（同步对调 `[P1, P4]` 与 `[P2, P3]` 标签）、$\pm 15^\circ$ 仿射旋转、自适应光照抖动
- **损失函数**：加权均方误差（Weighted Heatmap MSE Loss）

### 2. 收敛曲线与验证集指标
在 TITAN RTX 上针对动车组典型高清工况数据集训练 60 Epochs：
- **Epoch 6**：PCK@0.05 突破 **92.2%**，PCK@0.10 达到 **96.9%**；
- **Epoch 9**：PCK@0.05 达到 **99.7%**，PCK@0.10 达到 **100.0%**；
- **Epoch 32**：PCK@0.05 达到 **100.0%**（所有关键点定位误差严格落在真值半径 5% 范围之内），权重最终固化为 `best_hrnet_w32_panto.pth`。

## 四、致命误区：为什么图像绝对坐标系在工业现场必然导致 50%+ 误报？

有了精准的 4 关键点坐标后，最初我们采用了一种直觉性的几何判定方案：
分别计算上滑板线（$P_1-P_4$）和下横梁线（$P_2-P_3$）相对于**图像水平 X 轴**的角度，并直接求平均：

$$\theta_{\text{horn}} = \arctan2(y_4 - y_1, \ x_4 - x_1) \times \frac{180^\circ}{\pi}$$

$$\theta_{\text{support}} = \arctan2(y_3 - y_2, \ x_3 - x_2) \times \frac{180^\circ}{\pi}$$

$$\theta_{\text{fused}} = \frac{\theta_{\text{horn}} + \theta_{\text{support}}}{2}$$

如果 $|\theta_{\text{fused}}| \ge 1.8^\circ$，就判定为倾斜报警。

### 现场惨痛教训：全视频报警率竟高达 52.5%！
我们将该算法部署到一段标准的动车组运行视频（`tilt_1.mp4`，共 120 秒，按 1 FPS 抽样 120 帧）中进行测试，统计报表令人瞠目结舌：
- **NORMAL (正常)**：仅 37 帧（30.8%）
- **WARNING (预警)**：19 帧（15.8%）
- **ALARM (严重告警)**：**高达 63 帧（52.5%）！**

为什么在列车平稳行驶的大部分时间里，算法都在疯狂报假警？

```
      图像绝对水平 X 轴 ----------------------------------------------------->
                               \  相机安装滚转角误差 θ_bias ≈ +2.0°
                                \------------------------------------>
                                 \     受电弓实际结构 (完好平行，并未损坏！)
                                  ●================================● P1-P4 (+2.4°)
                                  ●--------------------------------● P2-P3 (+1.6°)
```

### 根因剖析：图像坐标系 $\neq$ 物理机械参考系
在工业车载机器视觉中，图像坐标系会受到三重不可抗力因素的严重“污染”：
1. **相机安装滚转偏差（Camera Roll Bias）**：车顶巡检相机底座由螺栓固定，施工安装通常不可避免地存在 **$1.5^\circ \sim 2.5^\circ$** 的微小水平误差；
2. **铁路线路过弯超高角（Superelevation / Cant）**：高铁进入弯道时，外轨抬高以平衡离心力，列车全车（连同车体、相机和受电弓整体）会整体侧偏 **$2^\circ \sim 6^\circ$**；
3. **车体动态晃动**：列车在高速行驶中的空气阻力和转向架横向振颤，使整车在相机画面里发生全局高频摇摆。

**结论**：把“图像水平轴”当作“受电弓姿态基准”，是典型的外参耦合错误！$\theta_{\text{horn}}$ 和 $\theta_{\text{support}}$ 同时偏转 2°，只代表**相机没装正**或者**车在过弯**，根本不代表受电弓发生了机械故障！

## 五、数学推导：基于下横梁局部浮动基准系的 SO(2) 不变性解算

真正有物理意义的受电弓结构故障，是**上滑板相对于下横梁是否还保持严格平行**！
因为受电弓内部由平行四边形铰链与立柱弹簧盒支撑，无论整列火车倾斜多少度、相机安装歪多少度，正常的弓头内部结构上滑板（$P_1-P_4$）必须与下横梁（$P_2-P_3$）保持严格平行。

因此，我们必须**以下横梁（$P_2 \rightarrow P_3$）作为局部浮动坐标系的基准 $X_{\text{local}}$ 轴**！

```
                    P1 (左羊角)                      P4 (右羊角)
                     ●================================●   <--- 向量 v_horn (上滑板)
                     |                                |
                     |      θ_rel (局部相对平行偏角)    |
                     |                                |
                     ●--------------------------------●   <--- 向量 v_base (局部 X 基准轴)
                 P2 (左支撑)                      P3 (右支撑)
```

在 2D 平面中，无需做复杂的相机逆标定矩阵转换，直接借助**二维几何向量的点积与二维叉积**即可优雅求解带方向的夹角：

### 1. 定义几何向量
- **下横梁局部基准向量**：
  $$\vec{v}_{\text{base}} = \vec{P_2 P_3} = \begin{bmatrix} x_3 - x_2 \\ y_3 - y_2 \end{bmatrix} = \begin{bmatrix} \Delta x_{\text{base}} \\ \Delta y_{\text{base}} \end{bmatrix}$$
- **上滑板目标向量**：
  $$\vec{v}_{\text{horn}} = \vec{P_1 P_4} = \begin{bmatrix} x_4 - x_1 \\ y_4 - y_1 \end{bmatrix} = \begin{bmatrix} \Delta x_{\text{horn}} \\ \Delta y_{\text{horn}} \end{bmatrix}$$

### 2. 内积与外积解算（点乘与叉乘）
- **向量点积（衡量同向投影与模长）**：
  $$\text{Dot} = \vec{v}_{\text{base}} \cdot \vec{v}_{\text{horn}} = \Delta x_{\text{base}} \cdot \Delta x_{\text{horn}} + \Delta y_{\text{base}} \cdot \Delta y_{\text{horn}}$$
- **二维伪标量叉积（衡量垂直旋转分量与正负方向）**：
  $$\text{Cross} = \vec{v}_{\text{base}} \times \vec{v}_{\text{horn}} = \Delta x_{\text{base}} \cdot \Delta y_{\text{horn}} - \Delta y_{\text{base}} \cdot \Delta x_{\text{horn}}$$

### 3. 局部相对平行度偏角公式
$$\theta_{\text{rel}} = \operatorname{atan2}(\text{Cross}, \ \text{Dot}) \times \frac{180^\circ}{\pi}$$

### 4. 几何性质与物理判据
- **严格满足 $SO(2)$ 刚体旋转不变性**：若相机坐标系旋转任意角度 $\alpha$，向量 $\vec{v}_{\text{base}}$ 与 $\vec{v}_{\text{horn}}$ 的点积与叉积大小不变，$\theta_{\text{rel}}$ 的解算值严格守恒！
- **$\theta_{\text{rel}} = 0^\circ$**：上滑板与下横梁绝对平行（结构完全健康）；
- **$\theta_{\text{rel}} > 0^\circ$**：上滑板相对下梁顺时针偏折（**右端相对下塌，RIGHT_DROP**）；
- **$\theta_{\text{rel}} < 0^\circ$**：上滑板相对下梁逆时针偏折（**左端相对下塌，LEFT_DROP**）。

## 六、工程决策：为什么必须坚持“纯条件 A”以免疫摄像头偏移？

在建立了局部坐标系后，系统内实际上产生了两个维度的指标：
- **条件 A（结构性平行度偏角 $\theta_{\text{rel}}$）**：上滑板相对下梁偏了多少度；
- **条件 B（基线绝对倾角 $\theta_{\text{support}}$）**：下横梁在相机画面中偏了多少度（减去预设安装偏置后的整弓倾角 $\theta_{\text{rigid}}$）。

最初我们设计了双层触发机制：满足条件 A **或** 条件 B 任一超限即报警。然而与一线维保团队深入研讨后，我们做出了一个关键的工程决策：**坚决砍掉条件 B，仅保留【条件 A】作为受电弓倾斜报警的唯一准则！**

### 核心决策依据：
在实际运行工况中，摄像头底座经过数千公里的高速振动冲击，不可避免会产生紧固件微松、角度轻微移位。如果将条件 B 纳入报警：
- **相机自身的安装松动移位，会被系统错误归因于“受电弓故障”**；
- 维护人员上车排查发现受电弓完好无损，导致对自动化监测系统的信任度归零。

因此，在技术体系中完成明确职责划界：
1. **条件 A（$\theta_{\text{rel}}$）**：作为**受电弓倾斜故障的唯一判定依据**，完全杜绝摄像头任何位移引起的假报警；
2. **条件 B（$\theta_{\text{support}}$）**：仅作为**巡检摄像头自身位姿健康度的辅助监控日志**，当发现 $\theta_{\text{support}}$ 长期偏离正常中位数时，系统生成“请校准/紧固车顶摄像头”的设备维护工单，而不向行车调度报出受电弓假故障！

## 八、生产级参考实现与技术总结

以下为提炼出的工业级 Python 核心解算模块代码，已封装向量化运算与鲁棒门控：

```python
import numpy as np

def compute_pantograph_tilt_v2(
    kpts,
    structural_warning_thresh=1.2,
    structural_alarm_thresh=1.8,
    install_bias_deg=2.0,
):
    """
    受电弓 4 关键点局部浮动基准系倾斜解算 (纯条件 A 工业抗虚警方案)
    
    参数:
      kpts: (4, 2) 或 (4, 3) 关键点数组 [P1, P2, P3, P4]
            P1: 左羊角, P2: 左支撑, P3: 右支撑, P4: 右羊角
      structural_warning_thresh: 相对平行度预警阈值 (默认 1.2°)
      structural_alarm_thresh:   相对平行度告警阈值 (默认 1.8°)
      install_bias_deg:          相机静态安装偏置 (仅作辅助参考日志)
    """
    coords = np.array(kpts, dtype=np.float64)[:, :2]
    p1, p2, p3, p4 = coords[0], coords[1], coords[2], coords[3]

    # 1. 构造局部基准向量与工作滑板向量
    v_base = p3 - p2  # 下横梁基准 P2 -> P3 (局部 X 轴)
    v_horn = p4 - p1  # 上滑板向量 P1 -> P4

    # 2. 向量点积与二维叉积 (构造 SO(2) 刚体旋转不变量)
    dot = float(v_base[0] * v_horn[0] + v_base[1] * v_horn[1])
    cross = float(v_base[0] * v_horn[1] - v_base[1] * v_horn[0])
    
    # 3. 局部相对平行度偏角 (条件 A)
    theta_rel = float(np.degrees(np.arctan2(cross, dot)))

    # 4. 辅助观测指标 (供相机位姿巡检排错，不参与受电弓故障报警)
    theta_support = float(np.degrees(np.arctan2(v_base[1], v_base[0])))
    theta_horn = float(np.degrees(np.arctan2(v_horn[1], v_horn[0])))
    theta_rigid = theta_support - install_bias_deg

    # 5. 严格基于条件 A 的故障分级判据
    abs_rel = abs(theta_rel)
    direction = "RIGHT_DROP" if theta_rel > 0 else "LEFT_DROP"
    if abs_rel < structural_warning_thresh:
        direction = "PARALLEL"

    is_alarm = (abs_rel >= structural_alarm_thresh)
    is_warning = (abs_rel >= structural_warning_thresh) and not is_alarm

    if is_alarm:
        status = "ALARM_TILT"
        severity = "CRITICAL"
    elif is_warning:
        status = "WARNING_TILT"
        severity = "WARNING"
    else:
        status = "NORMAL"
        severity = "NORMAL"

    return {
        "status": status,
        "severity": severity,
        "is_alarm": is_alarm,
        "tilt_direction": direction,
        "relative_tilt_deg": round(theta_rel, 2),       # 条件 A 核心指标
        "support_angle_deg": round(theta_support, 2),   # 相机基线角
        "horn_angle_deg": round(theta_horn, 2),
        "horn_drop_px": round(float(v_horn[1]), 1),
        "support_drop_px": round(float(v_base[1]), 1),
    }
```

### 核心技术心得总结：
1. **不要试图在动态磨损面上打点**：避开受电弓中央接触摩擦区，将特征点收敛到羊角顶点与下梁刚性铰接点，是姿态回归抗干扰的第一要务；
2. **永远警惕“图像绝对水平”的虚假假设**：工业巡检相机永远不会绝对水平，线路永远存在曲线超高。唯有**构建机件内蕴的局部几何基准系**，才能实现数学上的真正鲁棒；
3. **报警准则宁精勿杂**：辅助指标虽好，但不应轻易混入故障主干逻辑。将可能由传感器偏移引起的指标降为健康日志，只对纯物理结构变形发出严重声光报警，是工业 AI 算法避免被现场用户“拔插头”的关键分水岭。
