> **导读**：高铁运行中，受电弓上横板倾斜可能导致受流恶化、拉弧，甚至引发严重的断线事故。在实际应用机器视觉进行倾斜检测时，我们遇到了两个主要问题：一是滑板中央的不均匀磨损导致传统的边缘拟合方法失效；二是相机的安装误差和列车过弯时的车体倾斜会导致基于图像绝对角度的算法频繁误报。
>
> 本文记录了我们优化受电弓 2D 倾斜监测系统的过程。主要包括：将特征点从 10 个精简为 4 个刚性特征点以避开磨损区；使用 HRNet-W32 进行关键点定位；推导并采用基于下横梁局部参考基准的平行度计算方法。最终，通过调整报警逻辑（仅参考相对平行度），我们将测试视频中的虚警率从 52.5% 降低到了 3.3%，并能有效识别真实的倾斜故障。

## 一、问题背景：受电弓倾斜监测的难点

受电弓是动车组获取电能的重要部件。运行时，受电弓碳滑板需要与接触网保持水平接触和稳定的压力。如果受电弓发生横向倾斜（例如由于单侧弹簧盒断裂、气囊漏气或异物干扰等原因）：
1. 单侧受力集中，另一侧脱离接触网，容易产生剧烈的离线拉弧现象；
2. 翘起的羊角可能钻入接触网零件或分段绝缘器下方，引发严重的断线事故（钻弓）。

```
       正常水平受流 (平衡接触)                  倾斜异常受流 (单侧脱弓、强拉弧风险)
接触网: --------------------------      接触网: ---------/----------------
受电弓: [========================]      受电弓:         / (右端下塌，左端翘起)
           ||                ||                       ||                ||
```

在实际的车顶巡检视频分析中，视觉算法经常会受到以下因素的干扰：
- **碳滑板长期磨损**：滑板中心区域在接触摩擦后会变薄形成凹槽，直接检测边缘很难得到准确的直线；
- **强光干扰**：夜间离线拉弧产生的强光过曝会导致边缘特征模糊；
- **车体晃动和倾斜**：列车过弯时的外轨抬高以及高速行驶中的横向晃动，会使相机画面发生整体倾斜，导致原本基于图像水平线的判断方法失效。

## 二、特征点方案：从 10 点精简到 4 个刚性点

在项目初期，我们尝试在碳滑板上表面密集标注 6~10 个关键点。后来在工程实践中发现这种方式存在不少问题。

```
初期方案 (6~10点密集型，易受磨损影响):
   (1)---(2)-------(3)--------(4)-------(5)---(6)   <-- 碳滑板磨耗工作面 (厚度动态变化)
           \-------(7)========(8)-------/           <-- 下托架

演进方案 (4点刚性解耦型，避开中心接触区):
   P1 (左羊角顶点) ============================== P4 (右羊角顶点)  <-- 刚性工作跨度
       \                                           /
        \--- P2 (左支撑铰点) ======= P3 (右支撑铰点) ---/            <-- 刚性安装基准
```

### 1. 避开中央磨损区
碳滑板是用碳陶复合材料制作的易耗件，接触线在滑板中央滑行会逐渐磨出凹槽。如果在滑板表面标注关键点，这些点的位置会随着磨损深度改变。算法很容易把这种正常的磨损凹陷误判为结构弯曲或异常倾斜。

### 2. 4个刚性关键点方案
为了避开磨损的影响，我们最终选择了 4 个受磨损影响较小的特征点：

| 标识 | 拓扑命名 | 位置说明 | 选择原因 |
| :---: | :--- | :--- | :--- |
| **P1** | `p1_left_horn` | 碳滑板左侧羊角弯折顶点 | 位于最外侧，不与接触网直接摩擦，跨度大有助于提高角度计算精度 |
| **P2** | `p2_left_support` | 下横梁与左 U 形支架交接点 | 内部刚性交接点，不受滑板磨损影响 |
| **P3** | `p3_right_support`| 下横梁与右 U 形支架交接点 | 与 P2 对称，共同构成下横梁基准线 |
| **P4** | `p4_right_horn` | 碳滑板右侧羊角弯折顶点 | 位于右侧最外端，与 P1 连线代表上滑板姿态 |

这个改动减少了标注工作量，同时也排除了滑板正常磨损对倾斜角度计算的干扰。

## 三、模型训练：基于 HRNet-W32 的关键点定位

关于骨干网络，我们选择了 HRNet-W32。相比于传统的先下采样再上采样的网络结构，HRNet 在整个特征提取过程中始终保持了高分辨率的分支，有助于提升关键点定位的精度。

![HRNet 网络结构](https://raw.githubusercontent.com/leoxiaobin/deep-high-resolution-net.pytorch/master/figures/hrnet.png)
*HRNet 的多分辨率并行特征交换结构。*

### 1. 训练参数设置
- **输入分辨率**：$384 \times 288$（宽高比适配受电弓的横条结构）
- **输出热图分辨率**：$96 \times 72$
- **解码方法**：双线性插值 + DarkPose 亚像素极值修正
- **数据增强**：随机水平翻转（同步对调左右关键点标签）、$\pm 15^\circ$ 仿射旋转、光照调整
- **损失函数**：Weighted Heatmap MSE Loss

### 2. 训练结果
在使用 TITAN RTX 训练 60 个 Epoch 后，验证集指标表现较好：
- **Epoch 6**：PCK@0.05 超过 92%，PCK@0.10 达到 96.9%；
- **Epoch 32**：PCK@0.05 达到 100.0%（所有关键点定位误差均落在真值半径 5% 的范围内）。模型权重保存为 `best_hrnet_w32_panto.pth`。

## 四、现场问题：绝对坐标系导致的频繁误报

确定了关键点位置后，我们最初的想法是分别计算上滑板连线（$P_1-P_4$）和下横梁连线（$P_2-P_3$）相对于图像水平轴的角度，然后求两者的平均值：

$$\theta_{\text{horn}} = \arctan2(y_4 - y_1, \ x_4 - x_1) \times \frac{180^\circ}{\pi}$$

$$\theta_{\text{support}} = \arctan2(y_3 - y_2, \ x_3 - x_2) \times \frac{180^\circ}{\pi}$$

$$\theta_{\text{fused}} = \frac{\theta_{\text{horn}} + \theta_{\text{support}}}{2}$$

如果 $|\theta_{\text{fused}}| \ge 1.8^\circ$，系统就会发出倾斜告警。

### 现场测试的频繁误报
我们在一段包含动车组典型运行工况的视频（`tilt_1.mp4`，时长 120 秒，按 1 FPS 抽样 120 帧）中测试了这个算法，结果不太理想：
- **NORMAL (正常)**：37 帧 (30.8%)
- **WARNING (预警)**：19 帧 (15.8%)
- **ALARM (告警)**：63 帧 (52.5%)

列车在平稳行驶的大部分时间里，系统都在频繁给出告警。

```
      图像绝对水平 X 轴 ----------------------------------------------------->
                               \  相机安装误差 θ_bias ≈ +2.0°
                                \------------------------------------>
                                 \     受电弓实际结构 (完好平行，并未损坏)
                                  ●================================● P1-P4 (+2.4°)
                                  ●--------------------------------● P2-P3 (+1.6°)
```

### 误报原因分析
问题在于，图像中的水平线并不等同于物理世界的水平线。在车载环境中，图像角度会受到以下因素的影响：
1. **相机安装误差**：车顶相机的安装底座很难做到绝对水平，往往有 $1.5^\circ \sim 2.5^\circ$ 的安装偏差；
2. **铁路线路过弯超高**：高铁过弯时，外轨抬高会使列车车体（连同相机）整体偏离水平面 $2^\circ \sim 6^\circ$；
3. **车体晃动**：列车高速行驶时的空气阻力和转向架横向振动，会使画面产生整体摆动。

因此，如果发现 $\theta_{\text{horn}}$ 和 $\theta_{\text{support}}$ 同时偏转 2°，很可能只是相机没装平或者列车正在过弯，并不能说明受电弓内部结构发生了故障。

## 五、改进方案：基于局部基准系的相对角度计算

为了排除整车倾斜和相机安装误差的影响，我们需要关注受电弓内部结构的相对形态。在正常情况下，受电弓的内部铰链结构会保证其上滑板（$P_1-P_4$）与下横梁（$P_2-P_3$）基本平行。

因此，我们可以把下横梁作为局部的参考基准，计算上滑板相对于它的相对夹角。

```
                    P1 (左羊角)                      P4 (右羊角)
                     ●================================●   <--- 向量 v_horn (上滑板)
                     |                                |
                     |      θ_rel (相对夹角)            |
                     |                                |
                     ●--------------------------------●   <--- 向量 v_base (局部基准轴)
                 P2 (左支撑)                      P3 (右支撑)
```

使用二维向量可以方便地求出这个带方向的相对角度：

### 1. 定义向量
- **下横梁基准向量**：
  $$\vec{v}_{\text{base}} = \vec{P_2 P_3} = \begin{bmatrix} x_3 - x_2 \\ y_3 - y_2 \end{bmatrix} = \begin{bmatrix} \Delta x_{\text{base}} \\ \Delta y_{\text{base}} \end{bmatrix}$$
- **上滑板向量**：
  $$\vec{v}_{\text{horn}} = \vec{P_1 P_4} = \begin{bmatrix} x_4 - x_1 \\ y_4 - y_1 \end{bmatrix} = \begin{bmatrix} \Delta x_{\text{horn}} \\ \Delta y_{\text{horn}} \end{bmatrix}$$

### 2. 计算相对角度
利用向量的点积和叉积计算夹角：
- 点积：$\text{Dot} = \Delta x_{\text{base}} \cdot \Delta x_{\text{horn}} + \Delta y_{\text{base}} \cdot \Delta y_{\text{horn}}$
- 叉积：$\text{Cross} = \Delta x_{\text{base}} \cdot \Delta y_{\text{horn}} - \Delta y_{\text{base}} \cdot \Delta x_{\text{horn}}$

$$\theta_{\text{rel}} = \operatorname{atan2}(\text{Cross}, \ \text{Dot}) \times \frac{180^\circ}{\pi}$$

### 3. 结果判断
- 这个相对角度 $\theta_{\text{rel}}$ 不受相机整体旋转的影响。
- $\theta_{\text{rel}} \approx 0^\circ$：上滑板与下横梁平行，受电弓结构正常；
- $\theta_{\text{rel}} > 0^\circ$：上滑板相对下横梁顺时针倾斜（右侧相对下塌）；
- $\theta_{\text{rel}} < 0^\circ$：上滑板相对下横梁逆时针倾斜（左侧相对下塌）。

## 六、报警逻辑：只依赖相对平行度（条件 A）

在使用局部基准系后，我们实际得到了两个角度指标：
- **条件 A（相对夹角 $\theta_{\text{rel}}$）**：上滑板相对于下横梁的夹角。
- **条件 B（绝对角度 $\theta_{\text{support}}$）**：下横梁在图像中的绝对倾角。

最初我们考虑双重条件：只要条件 A 或条件 B 有一个超标就报警。但在实际运行中，相机底座由于长期振动可能会出现轻微松动或移位。如果保留条件 B，相机的移位就会触发系统持续告警。维护人员去现场排查却发现受电弓完好无损，这会降低他们对系统的信任。

经过考量，我们调整了策略，只保留条件 A 作为受电弓倾斜告警的判定依据。条件 B 则作为后台日志数据，用于监控相机的安装状态。如果条件 B 持续异常，系统会生成检查相机安装的提示，而不是直接报出受电弓故障。

## 八、参考代码与总结

以下是使用 Python 编写的核心角度计算模块参考代码：

```python
import numpy as np

def compute_pantograph_tilt(
    kpts,
    warning_thresh=1.2,
    alarm_thresh=1.8,
    install_bias_deg=2.0,
):
    """
    计算受电弓上滑板相对于下横梁的倾斜角度。
    
    参数:
      kpts: (4, 2) 或 (4, 3) 关键点数组 [P1, P2, P3, P4]
            P1: 左羊角, P2: 左支撑, P3: 右支撑, P4: 右羊角
      warning_thresh: 相对夹角预警阈值
      alarm_thresh:   相对夹角告警阈值
      install_bias_deg: 预期的相机安装偏置（用于后台日志记录，不参与报警判定）
    """
    coords = np.array(kpts, dtype=np.float64)[:, :2]
    p1, p2, p3, p4 = coords[0], coords[1], coords[2], coords[3]

    # 1. 构造向量
    v_base = p3 - p2  # 下横梁向量 (基准轴)
    v_horn = p4 - p1  # 上滑板向量

    # 2. 计算点积与叉积
    dot = float(v_base[0] * v_horn[0] + v_base[1] * v_horn[1])
    cross = float(v_base[0] * v_horn[1] - v_base[1] * v_horn[0])
    
    # 3. 计算相对夹角 (条件 A)
    theta_rel = float(np.degrees(np.arctan2(cross, dot)))

    # 4. 计算绝对角度 (用于辅助监控日志)
    theta_support = float(np.degrees(np.arctan2(v_base[1], v_base[0])))
    theta_horn = float(np.degrees(np.arctan2(v_horn[1], v_horn[0])))

    # 5. 告警状态判定
    abs_rel = abs(theta_rel)
    direction = "RIGHT_DROP" if theta_rel > 0 else "LEFT_DROP"
    if abs_rel < warning_thresh:
        direction = "PARALLEL"

    is_alarm = (abs_rel >= alarm_thresh)
    is_warning = (abs_rel >= warning_thresh) and not is_alarm

    if is_alarm:
        status = "ALARM_TILT"
    elif is_warning:
        status = "WARNING_TILT"
    else:
        status = "NORMAL"

    return {
        "status": status,
        "is_alarm": is_alarm,
        "tilt_direction": direction,
        "relative_tilt_deg": round(theta_rel, 2),       # 核心判据
        "support_angle_deg": round(theta_support, 2),   # 参考指标
        "horn_angle_deg": round(theta_horn, 2),
    }
```

### 总结
1. **关键点位置的选择**：避开中央容易磨损的区域，将特征点定在相对固定的结构位置上，可以减少模型在实际环境中的定位偏差。
2. **结合物理结构**：在车载监控场景中，图像坐标系很难做到绝对水平。寻找物理结构内部的相对基准，能够更好地排除外部环境变化带来的影响。
3. **报警逻辑的设定**：尽量将可能由设备自身状态（如相机松动）导致的变化与监测目标隔离。清晰和专一的报警条件，有助于提高监控系统的可靠性和使用体验。
