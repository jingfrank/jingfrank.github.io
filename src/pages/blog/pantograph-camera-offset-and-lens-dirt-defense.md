## 一、现场工况痛点与技术冲突

在高速铁路车载边缘智能运维系统中，视频监控并非实验室里的理想恒温机位，而是一个长期暴露于剧烈振动、气动风阻和昼夜温差环境下的工业视觉系统。

```
                    ┌─────────────────────────┐
                    │ 接触网悬挂异物 / 电网开集 │
                    └───────────┬─────────────┘
                                │
                    ┌───────────▼─────────────┐
                    │ 受电弓横梁 (居中 / 偏转) │
                    └───────────┬─────────────┘
                                │
       ┌────────────────────────┴────────────────────────┐
       ▼                                                 ▼
【正常居中监控视场】                           【机位偏移 / 剧烈晃动视场】
· 受电弓完整位于画幅中央                       · 受电弓紧贴顶部/右侧边缘被切断
· 背景高速掠过，车体位置稳定                   · YOLO 检测置信度跌穿门限 (0.85 -> 0.02)
· 物理脏污在相机系下静止                       · 误触发无监督异常与车顶伪脏污累积
```

### 1. 机位偏转导致的“残损半弓”与“完全脱出”

在分析 CR400AF 与 CR400BF 现场下发的误报视频库时，我们发现了两类极为严峻的机位形变场景：
1. **上偏与顶边截断（如 G6307_A）**：工业镜头仰角被振动或维护人员无意推高，受电弓整体被推到画幅最顶部，$Y_1 \approx 0.0$，受电弓仅露出下半部支撑杆或半边横梁；
2. **右偏与出画脱出（如 G6909、G6310_A）**：机位向右偏转，受电弓横梁右侧端点紧贴 $X_2 = 1920$ 或 $2048$。在某些颠簸路段，受电弓向右进一步漂移，甚至**完全从右侧画幅边缘滑出，导致视场内仅能拍到空荡荡的天空或车顶绝缘子构件**。

### 2. 监控不全场景下的连锁误报反应链

当受电弓贴边残损甚至完全滑出画面时，下游各个原本设计精良的检测子模块会爆发连锁误报灾难：
- **YOLO 置信度断崖式下跌**：常规目标检测器（如 YOLOv11/YOLOv8）依赖完备的双侧角部对称几何先验。当受电弓只露出一半或紧贴边缘时，检测框置信度会从 $0.85 \sim 0.95$ 瞬间暴跌至 $0.019 \sim 0.05$。因为常规置信度过滤门限为 $0.30$，系统在无弓帧上判定为 `panto_bbox = None`；
- **结构异常误判**：旧版无监督异常检测（FastAD/PatchCore）若在固定 ROI 内找不到完整受电弓，就会认为受电弓“横梁大面积折断/缺失”，误报严重结构故障；
- **车顶构件累积为镜头脏污**：脏污检测器（`FastadDirtDetector`）核心是利用 EMA 衰减累积在相机坐标系下绝对静止的异常高频网格。当受电弓出画后，原本被弓身遮挡的车顶钣金构件、绝缘子或导流罩完整暴露在镜头下。这些车顶构件相对于相机是严格静止的，经过 3~4 秒的时序 EMA 累加，直接达到 `persistent_cells >= 6` 的脏污确诊阈值，在视频第 7~8 秒爆发严重的镜头脏污虚警！

### 3. “防车顶误报”与“保真实脏污”的深层工程博弈

为了压制上述车顶构件被误判为脏污的问题，上一轮优化中引入了两条激进规则：
1. **开阔视场校验（`sky_cells < 4`）**：假定“真正的镜头玻璃污染必然会污染到受电弓上方的开阔天空”，若受电弓上方天空网格活跃数 $< 4$，就强行判定为构件内部异常，每秒强行清空历史；
2. **监控不全一刀切熔断（`is_panto_incomplete`）**：一旦发现受电弓残损贴边，直接关闭脏污检测。

这两条规则虽然彻底消除了部分出画视频的虚警，却在现场引发了意想不到的“负面误伤”：**如果镜头正中央粘有一团极具安全隐患的鸟粪或油污（如 G6310_A），但受电弓上方的天空是干净的，该真实污渍就会被 `sky_cells < 4` 判定无情抹杀！**

工程优化的精髓，绝非“头痛医头、脚痛医脚”，而必须深入机理，建立兼具包容性与鲁棒性的多层解耦防御体系。

## 二、开集悬挂异物检测改造：从固定先验到动态 YOLO 引导

### 1. 静态 ROI 在机位颠簸下的几何失效

在早期版本中，悬挂异物检测器（`FastadForeignDetector`）采用基于机位先验的静态归一化切片：
```yaml
# 旧版静态切片参数
catenary_roi_ratio: [0.25, 0.25, 0.85, 0.50]
```
这种静态 ROI 假设受电弓永远处于画幅纵向 $[0.50, 0.85]$、接触网永远处于 $[0.25, 0.50]$。然而一旦列车发生剧烈颠簸、受电弓升降变化或相机安装俯仰角产生偏差，接触网导线往往脱出该静态矩形；更严重的是，受电弓横梁可能向上冲入该矩形区域，导致受电弓自身的金属横梁被当成接触网悬挂的开集异物反复报警。

### 2. 基于 YOLO 目标框的动态浮动接触网 ROI 算法

为了让异物检测器始终聚焦在“受电弓与接触网动态耦合受流点上方”，我们将接触网 ROI 改造为**基于 YOLO 实时检测框动态推导**的浮动自适应区域：

```python
# 动态接触网 ROI 推导逻辑
if context is not None and getattr(context, "panto_bbox", None) is not None:
    px1, py1, px2, py2 = context.panto_bbox
    self.last_valid_panto_bbox = context.panto_bbox
    self.last_panto_ts = current_ts
    
    pw = px2 - px1
    ph = py2 - py1
    
    # 动态锚定：以弓头顶端 (py1) 为基准，向上延伸接触网观测带
    cx1 = max(0, int(px1 - pw * 0.10))
    cx2 = min(w, int(px2 + pw * 0.10))
    cy2 = max(0, int(py1 + ph * 0.20))
    cy1 = max(0, int(py1 - ph * 1.50))
```

```
           ┌────────────────────────────────────────┐
           │        动态接触网浮动 ROI               │
           │  (cy1: py1 - 1.5*ph, cx1: px1 - 0.1*pw)│
           │  · 空间自适应随受电弓上下起伏浮动       │
           │  · 严格锁定在碳滑板受流点上空区域      │
           └───────────────────┬────────────────────┘
                               │
                       ┌───────▼───────┐
                       │  panto_bbox   │  YOLO 实时目标框
                       │  (受电弓本体)  │  (px1, py1, px2, py2)
                       └───────────────┘
```

通过将接触网区域的纵坐标 $cy_1, cy_2$ 紧密锚定在受电弓顶端 $py_1$ 之上，无论受电弓如何在行车中大幅度上下起伏弹跳，接触网分析区域始终完美贴合在受流接触面上方，彻底根除了几何切片错位问题。

### 3. 强电弧火花放电致盲下的时序保持机制 (BBox Hold)

在夜间或雨雪大风天，受电弓脱网会产生数十万坎德拉的极亮大火花放电。放电光斑会产生强烈的局部曝光过饱和（Bloom），导致 YOLO 在连续 $2 \sim 5$ 帧内暂时丢失受电弓轮廓（`panto_bbox = None`）。

如果此时动态 ROI 瞬间失效并跌落回全图或静态区域，系统就会产生不可预测的虚警。为此，我们建立了时序保持机制：
```python
# 强放电遮蔽期间的目标框惯性保持 (BBox Hold)
elif (self.last_valid_panto_bbox is not None and 
      current_ts - self.last_panto_ts <= self.panto_bbox_hold_sec):
    px1, py1, px2, py2 = self.last_valid_panto_bbox
    pw, ph = px2 - px1, py2 - py1
    cx1 = max(0, int(px1 - pw * 0.10))
    cx2 = min(w, int(px2 + pw * 0.10))
    cy2 = max(0, int(py1 + ph * 0.20))
    cy1 = max(0, int(py1 - ph * 1.50))
```
允许在放电强光致盲期间维持最后一次有效目标框长达 1.0 秒，保障了连续时序状态机不受瞬态闪光的干扰。

### 4. 检测尺度与置信度门限全面对齐

此前异物检测使用的参数与结构异常检测存在巨大割裂（`min_foreign_area: 100` vs `min_defect_area: 250`），导致接触网远景的细碎电线绝缘子接头频繁触发微小连通域告警。

我们将异物检测器的参数全面与结构异常对齐：
- 最小连通域缺陷面积下限统一提升至 `min_foreign_area: 250`；
- 全局图像级门限对齐为 `img_threshold: 8.5`；
- 像素级异常二值化门限对齐为 `pixel_threshold: 2.8`；
- 保留 `max_blobs_filter: 12` 密集桁架过滤，彻底杜绝列车进出站台经过高密度钢架网时的连片误报。

## 三、机位偏转与受电弓出画防御体系

### 1. 贴边残损弓识别与低置信度候选召回

针对前述由于受电弓被边缘截断导致 YOLO 置信度跌破常规 0.30 阈值的问题，我们在前哨模块 [`spark_detector.py`](file:///mnt/T4/jyb/gongwang_clean/core/detectors/spark_detector.py) 中重构了受电弓提取与完整度判定机制：

1. **下探推理置信度至 0.05**：
   在 YOLO 推理时，将候选下探至 `infer_conf = min(self.conf_thresh, self.panto_min_conf)`（即 0.05），捕获所有被边缘截断但尚未完全脱出视野的微弱目标候选；
2. **多通道分离处理**：
   - 对于大火花与中心受电弓正常监测，严格维持常规门限（`conf >= 0.30`）；
   - 对于低置信度候选集（`0.05 <= conf < 0.30`），进行**贴边截断物理特征分析**：
     ```python
     margin_x = max(30, int(img_w * 0.02))
     margin_y = max(25, int(img_h * 0.025))
     
     # 低置信度候选贴边召回
     edge_low_candidate = False
     for lpbox, lpconf in low_panto_boxes:
         lpx1, lpy1, lpx2, lpy2 = lpbox
         if (lpx1 <= margin_x or lpx2 >= img_w - margin_x or
             lpy1 <= margin_y or lpy2 >= img_h - margin_y):
             edge_low_candidate = True
             break
     ```

一旦命中贴边低置信度候选，系统明确知道：**受电弓没有消失，而是被物理边缘切断了！** 系统立即置位 `is_panto_incomplete = True`。

### 2. 受电弓出画时序平滑锁存状态机 (Temporal Latch)

受电弓一旦开始滑出画幅边缘，在列车运行的物理连续性规律下，它绝不可能在 0.5 秒或 1 秒内无故“瞬间复位”，而是会在脱出视野后持续漂移几秒钟，直到轨道曲线拉直或晃动平息。

因此，系统不能采用“逐帧无记忆”的状态判定，必须引入**时序平滑锁存状态机**：

```python
if is_panto_incomplete:
    self.last_incomplete_timestamp = timestamp
elif best_panto_box is not None and not touches_edge and not too_narrow:
    # 唯有画幅中心稳定重新检出完好完整中心受电弓，方可解除锁存
    is_panto_incomplete = False
    self.last_incomplete_timestamp = None
elif (self.last_incomplete_timestamp is not None and timestamp is not None and
      0 <= timestamp - self.last_incomplete_timestamp <= self.panto_incomplete_hold_sec):
    # 状态锁存：近期曾贴边残损，当前画面无弓，说明受电弓完全滑出画面外，维持残缺抑制！
    is_panto_incomplete = True
```

锁存窗口默认配置为 `panto_incomplete_hold_sec: 10.0` 秒。当受电弓从边缘滑出画幅后，在接下来的 10 秒无弓期间，系统始终保持锁定在“监控不完整”的受保护状态，直到在安全中心区域重新检出合格完整受电弓，才平稳解除锁存。

### 3. 全系检测器短路熔断机制

在共享上下文 [`DetectionContext`](file:///mnt/T4/jyb/gongwang_clean/core/data_types.py) 中，`is_panto_incomplete` 标志位由前哨模块生成后，向下游全系检测器广播：
- **`FastadStructDetector`**：立即短路，跳过 GPU 推理与特征比对，返回 `status: panto_incomplete_suppressed`，避免把边缘残损或完全丢失的弓身判为“结构断裂”；
- **`FastadForeignDetector`**：立即短路，返回 `status: panto_incomplete_suppressed`，避免把出画区域车顶绝缘子判为“开集异物”；
- **`FastadDirtDetector`**：在监控不全期间清空网格 EMA 时序累积，重置 `history_length = 0`，杜绝车顶静止构件累积虚警。

## 四、镜头脏污检测重构：废除天空单点误杀与 Layer 2 标定

### 1. 天空开阔视场先验 (`sky_cells < 4`) 的物理破绽

前文提到，旧版脏污检测器存在一条强先验规则：
```python
# 旧版天空熔断逻辑
top_grid = max(1, int(panto_bbox[1] / h_dirt_limit * gh))
sky_cells = int(np.sum(grid_active[:top_grid, :]))
if sky_cells < 4:
    self.dirt_grid_history = None
    return DetectionResult(is_abnormal=False)
```

这条逻辑在物理上有极其致命的盲区：
1. **污渍落点随机性**：鸟粪、虫尸、雨水水渍、润滑油脂是外界随机溅射到车载保护玻璃上的，它完全有可能精准粘附在保护玻璃的正中央、中部偏下甚至侧边，绝无任何物理法则强制规定“污渍必须延伸到受电弓上方天空”；
2. **切片硬边界误差**：受电弓在画面中的高度随列车运行剧烈起伏。受电弓抬高时，$panto\_bbox[1]$ 变小，`top_grid` 缩减到仅剩顶端寥寥数行网格。只要镜头中央有一块巴掌大的油污，就会因为恰好处于 `top_grid` 下方，导致 `sky_cells = 0`，直接被一票否决！

### 2. G6310_A 镜片中央污渍漏报诊断全记录

在实测真实污损视频 `20260404_06_08_104120423_G6310_A.MP4` 时，该破绽被淋漓尽致地暴露出来：
- 该视频中，镜头保护玻璃正中央有一块非常显著的半透明油水污渍；
- FastAD 模型异常总分持续处于 **$7.4 \sim 9.3$** 的极高异常态；
- 真实污渍投影在网格坐标系中处于 **第 16~20 行**（图像像素高度 $Y \in [334, 393]$）；
- 然而，受电弓横梁顶端位于像素高度 $Y = 269$，对应网格第 13 行，计算出的 `top_grid = 13`；
- 检测器只统计了 $0 \sim 13$ 行，得到的 `sky_cells` 恒等于 0；
- 结果触发了 `if sky_cells < 4:`，检测器在每一秒的采样点上都将时序累积强行抹零（`history_length = 0`），导致这块肉眼可见的严重镜片污染全程漏报！

```
     网格行号
      0 ┌──────────────────────────────────────────┐
        │  纯净天空 (sky_cells = 0)                 │
     13 ├──────────────────────────────────────────┤ ◄── top_grid (弓顶切线)
        │                                          │
     16 ├ - - - ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ - - - - - - -┤
        │       真实的物理油污斑块 (持续存在)         │ ◄── 被 sky_cells < 4 强行误杀抹除！
     20 ├ - - - ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ - - - - - - -┤
        │                                          │
     27 ├──────────────────────────────────────────┤ ◄── 受电弓横梁本体
        │              受电弓下部框架              │
```

### 3. 废除天空强行重置，回归全域 EMA 时序静止滤波

镜头脏污区别于任何动态缺陷（如火花、飘弓、飞鸟、路边树枝）的最本质物理特征，是**在工业相机本地像素坐标系下的“绝对绝对静止性”（Absolute Static Invariance）**。

列车在以 350 km/h 飞驰，外部所有的背景、树木、杆塔每秒都在画幅中移动成百上千个像素；哪怕受电弓自身，也在微幅高频颤动。**唯有镜头保护玻璃表面的污渍，其投影像素坐标在连续数十秒内纹丝不动！**

因此，我们断然**废除 `sky_cells < 4` 的天空强行熔断判定**，将算法重新拉回真正稳健的物理本质：
- 保留 `sky_cells` 仅作为诊断遥测字段，不再参与任何流程阻断；
- 依赖 **64×64 网格空间在相机物理坐标系下的 EMA 时序衰减累积**（$\alpha=0.85$）：
  $$Grid_{hist}^{(t)} = 0.85 \cdot Grid_{hist}^{(t-1)} + 0.15 \cdot Grid_{act}^{(t)}$$
- 只有当特定网格单元在连续 4 帧（3.0 秒）采样中持续处于异常激活态（$Grid_{hist} \ge 0.60$），且空间连通斑块达到 `min_active_cells: 6`，同时全局图像分数超标时，才确诊为光学镜面附着物污染。

### 4. FastAD Layer 2 像素阈值对齐与校准

在排查中我们还发现，在之前某次配置提交中，`dirt` 检测器的 `pixel_threshold` 被生硬地改成了 `4.5`，而 FastAD Layer 2 骨干网络在该特征层上的标准校准阈值（`calibrated_pixel_threshold`）实际上是 **$2.8 \sim 3.0$**。

在 `G6310_A` 中，镜面油污虽然清晰，但因其半透明特性，局部像素最大异常响应值为 $3.35$。过高的 $4.5$ 门限导致网格二值化像素被过滤得一干二净。我们将配置中的 `pixel_threshold` 严格对齐为 **$2.8$**，与 Layer 2 物理标定基准保持一致。

## 六、工程启示与总结

通过本次实战攻坚，动车组弓网边缘检测系统在面对复杂现场环境时，提炼出三条核心的抗虚警工程范式：

1. **摆脱死板几何先验，转向动态闭环引导**：
   车载颠簸与镜头偏转是物理不可避免的常态。固定切片（ROI）和死板的天空位置假设是脆弱误报的温床。上游 YOLO 的轻量检测框是最好的动态基准系，以受电弓实时姿态为锚点自适应伸缩推导，能以极低成本消除绝大部分几何错位；
2. **边缘效应的平滑锁存（Temporal Latching）**：
   目标边缘截断通常伴随着置信度雪崩。在单帧上做离散判定极易产生“检出-丢失-检出”的高频震荡。必须结合物理世界的惯性规律，用时序锁存状态机平滑出画过渡态，赋予检测系统抵抗临界扰动的阻尼特性；
3. **抓住物理不变量，克制过度工程化规则**：
   镜头脏污的核心不变量是**“相机物理像素系下的绝对时序静止性”**。任何自以为是的“必须在天空”、“不能在构件”等过度工程化规则，往往在解决某一个局部误报的同时，亲手制造了更多致命的现场漏报。唯有紧紧锚定物理本质，才能打造出真正经得起万里铁道线考验的高可靠工业级 AI 算法。
