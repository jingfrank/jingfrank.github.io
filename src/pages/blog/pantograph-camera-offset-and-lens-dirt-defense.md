## 一、现场工况痛点与技术冲突

高铁车载弓网监控系统长期处于振动、气动风阻和昼夜温差环境中，摄像头容易发生机械位移或仰角偏移。

```
                    ┌─────────────────────────┐
                    │ 接触网悬挂异物 / 电网开集 │
                    └───────────┬─────────────┘
                                │
                    ┌───────────▼─────────────┐
                    │ 受电弓横梁 (居中 / 偏转) │
                    └───────────┬─────────────┘
                                │
        ┌────────────────────────┴────────────────────────┐
        ▼                                                 ▼
【正常居中监控视场】                           【机位偏移 / 剧烈晃动视场】
· 受电弓完整位于画幅中央                       · 受电弓紧贴顶部/右侧边缘被切断
· 背景高速掠过，车体位置稳定                   · YOLO 检测置信度跌穿门限 (0.85 -> 0.02)
· 物理脏污在相机系下静止                       · 误触发无监督异常与车顶伪脏污累积
```

### 1. 机位偏转导致的“残损半弓”与“完全脱出”

分析 CR400AF 与 CR400BF 现场误报视频时，主要存在两类机位偏移：
1. **上偏与顶边截断（如 G6307_A）**：镜头仰角偏高，受电弓整体处于画幅顶部（$Y_1 \approx 0.0$），仅露出下半部支撑杆或局部横梁；
2. **右偏与出画脱出（如 G6909、G6310_A）**：机位右偏，受电弓横梁右端紧贴边缘（$X_2 = 1920$ 或 $2048$）。在部分颠簸路段，受电弓向右漂移完全滑出画幅，视场内仅剩下天空或车顶构件。

### 2. 监控不全场景下的连锁误报反应链

受电弓贴边残损或滑出画面后，下游检测模块会产生连带异常：
- **YOLO 置信度下降**：目标检测模型依赖整体结构特征。当受电弓贴边截断时，检测框置信度从 $0.85 \sim 0.95$ 降至 $0.019 \sim 0.05$。在默认置信度门限 $0.30$ 下，该帧被判定为 `panto_bbox = None`；
- **结构异常误判**：无监督异常检测（FastAD）在固定 ROI 内缺少完整受电弓特征，将残缺判定为构件缺失，输出结构异常告警；
- **车顶构件误报为脏污**：脏污检测器（`FastadDirtDetector`）通过网格 EMA 累积相机坐标系下的静止异常。受电弓出画后，原本被遮挡的车顶构件暴露在视野中。这些构件相对于相机保持静止，经过 3~4 秒 EMA 累积后满足 `persistent_cells >= 6`，在视频第 7~8 秒触发脏污误报。

### 3. “防车顶误报”与“保真实脏污”的深层工程博弈

为抑制车顶构件引发的脏污误报，此前曾引入两条规则：
1. **开阔视场校验（`sky_cells < 4`）**：假定镜头脏污必然延伸至受电弓上方的天空区域，若上方天空网格活跃数 $< 4$，则判定非脏污并清空历史；
2. **监控不全熔断（`is_panto_incomplete`）**：检测到受电弓残损贴边时暂停脏污检测。

但这两条规则带来了漏报：当镜头中央附着真实油污或水渍（如 G6310_A 样本），而受电弓上方天空清洁时，`sky_cells < 4` 会重置累积状态，导致真实脏污无法检出。因此需要解耦两者的判定逻辑。

## 二、开集悬挂异物检测改造：从固定先验到动态 YOLO 引导

### 1. 静态 ROI 在机位颠簸下的几何失效

早期版本中，悬挂异物检测器（`FastadForeignDetector`）使用固定区域切片：
```yaml
# 旧版静态切片参数
catenary_roi_ratio: [0.25, 0.25, 0.85, 0.50]
```
该切片假设受电弓处于画幅纵向 $[0.50, 0.85]$，接触网处于 $[0.25, 0.50]$。当列车起伏、受电弓升降或相机俯仰角发生偏移时，接触网导线容易移出该矩形；若受电弓横梁抬升进入该区域，还会把受电弓横梁误报为接触网异物。

### 2. 基于 YOLO 目标框的动态浮动接触网 ROI 算法

为保证异物检测区域跟随受电弓位置变化，我们将接触网 ROI 改为基于 YOLO 目标框动态推导的自适应区域：

```python
# 动态接触网 ROI 推导逻辑
if context is not None and getattr(context, "panto_bbox", None) is not None:
    px1, py1, px2, py2 = context.panto_bbox
    self.last_valid_panto_bbox = context.panto_bbox
    self.last_panto_ts = current_ts
    
    pw = px2 - px1
    ph = py2 - py1
    
    # 动态锚定：以弓头顶端 (py1) 为基准，向上延伸接触网观测带
    cx1 = max(0, int(px1 - pw * 0.10))
    cx2 = min(w, int(px2 + pw * 0.10))
    cy2 = max(0, int(py1 + ph * 0.20))
    cy1 = max(0, int(py1 - ph * 1.50))
```

```
           ┌────────────────────────────────────────┐
           │        动态接触网浮动 ROI               │
           │  (cy1: py1 - 1.5*ph, cx1: px1 - 0.1*pw)│
           │  · 空间自适应随受电弓上下起伏浮动       │
           │  · 严格锁定在碳滑板受流点上空区域      │
           └───────────────────┬────────────────────┘
                               │
                       ┌───────▼───────┐
                       │  panto_bbox   │  YOLO 实时目标框
                       │  (受电弓本体)  │  (px1, py1, px2, py2)
                       └───────────────┘
```

以受电弓顶端纵坐标 $py_1$ 为基准推导接触网区域坐标 $cy_1, cy_2$，使分析区域随受电弓浮动，避免了固定切片带来的位置错配。

### 3. 强电弧火花放电致盲下的时序保持机制 (BBox Hold)

夜间或恶劣天气下，受电弓离线产生的大火花可能导致局部过曝光，使 YOLO 在连续 $2 \sim 5$ 帧内漏检受电弓（`panto_bbox = None`）。

若此时动态 ROI 立即失效退回静态区域，易引发误报。为此增加了目标框时序保持机制（BBox Hold）：
```python
# 强放电遮蔽期间的目标框惯性保持 (BBox Hold)
elif (self.last_valid_panto_bbox is not None and 
      current_ts - self.last_panto_ts <= self.panto_bbox_hold_sec):
    px1, py1, px2, py2 = self.last_valid_panto_bbox
    pw, ph = px2 - px1, py2 - py1
    cx1 = max(0, int(px1 - pw * 0.10))
    cx2 = min(w, int(px2 + pw * 0.10))
    cy2 = max(0, int(py1 + ph * 0.20))
    cy1 = max(0, int(py1 - ph * 1.50))
```
在检测丢失后保留最后一次有效目标框 1.0 秒，平抑瞬态强光对 ROI 的影响。

### 4. 检测尺度与置信度门限全面对齐

此前异物检测与结构异常检测的参数不一致（`min_foreign_area: 100` 对比 `min_defect_area: 250`），远景绝缘子接头容易触发微小连通域误报。

本次对齐了异物检测器的参数：
- 最小连通域缺陷面积下限调整为 `min_foreign_area: 250`；
- 图像级异常阈值对齐为 `img_threshold: 8.5`；
- 像素级异常二值化阈值对齐为 `pixel_threshold: 2.8`；
- 保留 `max_blobs_filter: 12` 密集桁架过滤，过滤进出站台经过高密度钢架网时的连片误报。

## 三、机位偏转与受电弓出画防御体系

### 1. 贴边残损弓识别与低置信度候选召回

受电弓贴近边缘截断时，YOLO 置信度容易低于默认的 0.30 门限。我们在前哨模块 [`spark_detector.py`](file:///mnt/T4/jyb/gongwang_clean/core/detectors/spark_detector.py) 中调整了提取逻辑：

1. **下探推理候选置信度至 0.05**：
   YOLO 推理时使用 `infer_conf = min(self.conf_thresh, self.panto_min_conf)`（0.05），捕获贴边截断的低置信度候选；
2. **分流处理**：
   - 大火花与正常受电弓检测维持常规门限（`conf >= 0.30`）；
   - 低置信度候选（`0.05 <= conf < 0.30`）进行贴边位置校验：
     ```python
     margin_x = max(30, int(img_w * 0.02))
     margin_y = max(25, int(img_h * 0.025))
     
     # 低置信度候选贴边召回
     edge_low_candidate = False
     for lpbox, lpconf in low_panto_boxes:
         lpx1, lpy1, lpx2, lpy2 = lpbox
         if (lpx1 <= margin_x or lpx2 >= img_w - margin_x or
             lpy1 <= margin_y or lpy2 >= img_h - margin_y):
             edge_low_candidate = True
             break
     ```

命中贴边低置信度候选时，判定受电弓处于边缘截断状态，置位 `is_panto_incomplete = True`。

### 2. 受电弓出画时序平滑锁存状态机 (Temporal Latch)

受电弓移出画幅后通常会持续数秒，单帧离散判定容易在边缘临界点频繁抖动。为此引入时序锁存机制：

```python
if is_panto_incomplete:
    self.last_incomplete_timestamp = timestamp
elif best_panto_box is not None and not touches_edge and not too_narrow:
    # 唯有画幅中心稳定重新检出完好完整中心受电弓，方可解除锁存
    is_panto_incomplete = False
    self.last_incomplete_timestamp = None
elif (self.last_incomplete_timestamp is not None and timestamp is not None and
      0 <= timestamp - self.last_incomplete_timestamp <= self.panto_incomplete_hold_sec):
    # 状态锁存：近期曾贴边残损，当前画面无弓，说明受电弓完全滑出画面外，维持残缺抑制！
    is_panto_incomplete = True
```

锁存窗口配置为 `panto_incomplete_hold_sec: 10.0` 秒。当受电弓贴边出画后，在后续无弓期间保持 `is_panto_incomplete = True`；只有在中心区域重新检出完整的受电弓目标框时，才解除锁存。

### 3. 全系检测器短路熔断机制

共享上下文 [`DetectionContext`](file:///mnt/T4/jyb/gongwang_clean/core/data_types.py) 中的 `is_panto_incomplete` 标志位由前哨模块生成后传递给下游检测器：
- **`FastadStructDetector`**：跳过特征提取与比对，返回 `status: panto_incomplete_suppressed`，避免将残损或出画误判为结构折损；
- **`FastadForeignDetector`**：跳过检测并返回 `status: panto_incomplete_suppressed`，避免将暴露的车顶构件误判为异物；
- **`FastadDirtDetector`**：暂停网格 EMA 累积并重置历史，避免车顶静止部件累积为脏污。

## 四、镜头脏污检测重构：废除天空单点误杀与 Layer 2 标定

### 1. 天空开阔视场先验 (`sky_cells < 4`) 的物理破绽

旧版脏污检测器包含一条天空视场校验规则：
```python
# 旧版天空熔断逻辑
top_grid = max(1, int(panto_bbox[1] / h_dirt_limit * gh))
sky_cells = int(np.sum(grid_active[:top_grid, :]))
if sky_cells < 4:
    self.dirt_grid_history = None
    return DetectionResult(is_abnormal=False)
```

该判定存在两点局限：
1. **污渍位置随机**：玻璃表面的油水或污渍可能附着在镜片中央或下半部，并不一定出现在受电弓上方的天空区域；
2. **切片边界受弓位影响**：受电弓高度随运行起伏。当受电弓抬升时，`top_grid` 缩小，若污渍位于受电弓下方或中央，统计到的 `sky_cells` 为 0，导致检测被重置。

### 2. G6310_A 镜片中央污渍漏报诊断全记录

在实测视频 `20260404_06_08_104120423_G6310_A.MP4` 中确认了该现象：
- 镜头保护玻璃中央附着有半透明水油污渍；
- FastAD 图像异常分数处于 $7.4 \sim 9.3$；
- 污渍在 $64 \times 64$ 网格中位于第 16~20 行（像素高度 $Y \in [334, 393]$）；
- 受电弓横梁顶端位于像素高度 $Y = 269$（网格第 13 行），计算得到的 `top_grid = 13`；
- 统计第 $0 \sim 13$ 行网格时 `sky_cells` 为 0，触发 `sky_cells < 4` 判定并重置历史，导致该段真实污渍未产生告警。

```
     网格行号
      0 ┌──────────────────────────────────────────┐
        │  上方天空区域 (sky_cells = 0)             │
     13 ├──────────────────────────────────────────┤ ◄── top_grid (弓顶切线)
        │                                          │
     16 ├ - - - ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ - - - - - - -┤
        │       真实油污斑块 (持续存在)              │ ◄── 曾被 sky_cells < 4 规则误重置
     20 ├ - - - ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ - - - - - - -┤
        │                                          │
     27 ├──────────────────────────────────────────┤ ◄── 受电弓横梁
        │              受电弓下部框架              │
```

### 3. 废除天空强行重置，回归全域 EMA 时序静止滤波

镜头污渍与外部动态目标的区别在于其在相机坐标系下的时序静止性。列车行驶时，外部背景与受电弓均在运动，而保护玻璃上的污渍在像素坐标中保持相对静止。

据此废除 `sky_cells < 4` 的重置逻辑，依托网格时序滤波进行判断：
- `sky_cells` 仅作为遥测字段输出，不阻断检测流程；
- 采用 $64 \times 64$ 网格在相机坐标系下的 EMA 累积（$\alpha=0.85$）：
  $$Grid_{hist}^{(t)} = 0.85 \cdot Grid_{hist}^{(t-1)} + 0.15 \cdot Grid_{act}^{(t)}$$
- 网格单元在连续 4 帧（采样周期约 3.0 秒）中持续激活（$Grid_{hist} \ge 0.60$），且连通网格数达到 `min_active_cells: 6`、全局图像异常分数超标时，判定为画面脏污。

### 4. FastAD Layer 2 像素阈值对齐与校准

排查中同时发现此前配置中 `dirt` 检测器的 `pixel_threshold` 被修改为 `4.5`，而 FastAD Layer 2 骨干特征的标准校准阈值为 $2.8 \sim 3.0$。

在 `G6310_A` 样本中，半透明油污的局部像素异常最大响应为 $3.35$，$4.5$ 的阈值会导致网格二值化无法激活。修改后将 `pixel_threshold` 恢复为 `2.8`，与标定基准保持一致。

## 六、工程启示与总结

本次调整针对机位偏移和镜头脏污梳理了以下处理方式：

1. **采用动态 ROI 替代固定几何切片**：
   列车振动与镜头偏移会使受电弓位置产生偏差。以上游 YOLO 检测框为基准动态推导接触网区域，避免了固定切片因目标位移导致的几何错配；
2. **引入边缘状态时序锁存**：
   目标贴近边缘截断时置信度波动较大，单帧离散判定容易造成状态抖动。通过时序锁存平滑过渡区间，能够在受电弓出画阶段稳定维持抑制状态；
3. **基于相机坐标系下的静止特性判断脏污**：
   镜头污渍的核心特征在于其在图像像素坐标中的时序相对静止，而非局限于特定天空位置。去除空间位置假设、依赖多帧时序 EMA 累积，可以在保留车顶构件抑制的同时兼顾全镜面的真实污渍检出。
